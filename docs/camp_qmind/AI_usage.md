# Allowed usage of AI

There are 3 categories of development in CanopyMap and each will have different AI usage rules:

- Documentation
- Development
- Paper

## Documentation

Documentation may include:
- Comments in code
- Reports
- Project description
- Documentation in github
- Presentations/Pitch

### AI Usage in Documentation

You may not use AI to write documentation _for you_, however you absolutely can use it to gather, process, and categorize information. If the documentation you are writing is meant for humans, it should be written by a human. If it's meant for AI, such as [AGENTS.md](../../AGENTS.md) it can be written by AI with human supervision.

> *Why?* Many companies will force you to use AI for documentation for the sake of speed and getting documentation out of the way. Just because something is documented in a verbose manner, it does not mean that it is a _good_ documentation. *No documentation, is better than bad documentation*

### AI Usage in Development

You can use AI to try new ideas, check for bugs, or optimize your code. Since this project will not require too many lines of code, *it is recommended* that you _do not use_ agentic harnesses such as Claude Code, Codex, OpenCode, ... as they can abstract away too much of the content and you won't learn anything.

Getting help from AI to setup a dev environment and fix dependency issues is actually recommended.

Do not use AI to clean data for you, it will hallucinate half-way, however it can help you write code to clean your data.

Comments in code are not allowed to be written by AI, if the AI writes comments, you should replace them with what you understand from the code; as AI written comments are often as bad as its code :) .

> So I used AI to write this code snippet for me that does X and Y. What do I do now? Please ask the same AI to explain the code it wrote for you, line by line so you can learn its process and the libraries that its using. This way you learn and can write comments for important lines + easier to explain to your teammates when you're presenting your work.

### AI Usage in Paper

You should use AI to fix your grammar mistakes. But do not, under any circumstance use AI to write a paragraph for you when writing a paper. You may put down the content you want to write, in broken english and somewhat incoherent tone; later ask AI to help you formulate a flow to put in the paper, but stop it from giving you connection words or writing styles to use. It is *very easy to spot AI* written papers and defeats the purpose of learning how to write a paper.
